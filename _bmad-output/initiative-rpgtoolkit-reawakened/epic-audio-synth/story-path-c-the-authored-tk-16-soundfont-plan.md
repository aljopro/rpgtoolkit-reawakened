## Intent
Replace the unshipped borrowed-bank option with a project-owned, compact General MIDI SoundFont that is safe to redistribute and can be reviewed by listening. TK-16 is authored from deterministic mathematical waveforms, so no sample has an external copyright or an unclear chain of title.

## Boundaries & Constraints

**Always:** Keep the bank as an SF2 RIFF `sfbk` file below the 8 MiB gate ceiling. Record the bank hash, CC0-1.0 licence, and every sample's generator, loop, rate and source in `tools/licences/tk16-provenance.json`; keep the licence notice and gate record synchronized.

**Never:** Use ripped commercial or unverified third-party samples, add SoundFont bytes to core state, or activate TK-16 as the default before owner listening approval.

## Code Map

- `tools/licences/tk16_build.py` -- deterministic authoring source for the 16 melodic and one percussion waveform samples and SF2 tables.
- `tools/licences/tk16-provenance.json` -- per-sample provenance manifest and generated bank digest.
- `media/soundfonts/TK-16.sf2` -- generated runner-side RIFF SoundFont 2.1 bank.
- `tools/licences/config.json` -- `bundledAssets.soundfonts` gate record, hash and 8 MiB ceiling.
- `THIRD_PARTY_NOTICES` -- CC0 notice, bank digest and provenance reference.
- `docs/spec/engine/audio-media.md` -- Path C shipping and owner-listening status.

## Implementation Notes

The bank contains 16 melodic programs (MIDI programs 0–15), one bank-128 percussion program, 17 mono 22,050 Hz looping samples, and no external sample bytes. The bank is intentionally compact (37,560 bytes) and can be regenerated byte-for-byte by `tk16_build.py`.

The licence record uses `CC0-1.0` and `ADR-0003`; the notice repeats the exact gate `notice` string and includes the CC0 dedication. Path C is now the first bundled bank; the default-layer wording remains conditional on owner listening approval.

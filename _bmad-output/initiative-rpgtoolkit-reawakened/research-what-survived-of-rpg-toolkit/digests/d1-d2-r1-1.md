## Plugin-free proof candidates (shortlist)
1. **Final Destiny** (C. B. Matthews, 2002, TK2): it's the only game confirmed downloadable today (archive.org), and it's by the toolkit's own creator. It's a TK2-era game, so it probably predates heavy plugin use (unverified). Next: download it and look for a `Plugin/` folder or `.dll` files.
2. **Three Guys No Beer** (Brad, TK3.1): a short comedy game that was well liked. Plugin use is unknown. If it has battles it probably loads tk3fight.dll. Not downloadable today (not found).
3. **Grindalf's mini-games** (Eek, Galaxy Defender): arcade games that may avoid the battle and menu systems entirely. Unverified, and not found downloadable.
4. **The trans3 `demo` test game**: freely available, but it ships tk3fight/tk3menu DLLs, so it only counts if those are never called.

## Plugin-free share estimate
For TK3 games, any game that uses the default battle or menu needs a plugin. My guess is that at most ~30–50% of notable TK3 games were truly plugin-free, and those were mostly non-RPG or minigame titles. For TK2 games the share is probably higher. **Confidence: low.** No per-game manifest was inspected.

## Leads
- Download Final Destiny from archive.org and list its files for `.dll`s or a plugin list in the main game file.
- Inspect the archive.org GitHub bundle and the `rpgtoolkit/demo` repo.
- toolkitzone `games.php?game=N` pages (437 captured) and `files.php?file=N&dl` (63 captured) may hold archived zips. Try the Wayback `id_` fetch on the `&dl` URLs.
- toolkitzone `fileman/files/*.zip` captures (99, 135, 165, 237, 325, 595).
- Check whether TK2 has a built-in, non-plugin battle system. This decides whether TK2 games are plugin-free by default.

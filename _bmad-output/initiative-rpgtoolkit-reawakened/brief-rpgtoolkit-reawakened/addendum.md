# Addendum: RPG Toolkit Reawakened brief

Depth that informs the brief but doesn't fit in it. A quick web scan on 2026-10-10, so treat these findings as likely, not certain. The deeper research run will confirm or overturn them.

## Beginner RPG-maker landscape (2026)

- **RPG-specific tools are mostly desktop apps.**
  - RPG Maker MZ: about $80, proprietary. Beginners stall at its JavaScript plugins (r/RPGMaker threads, 2021–24).
  - OHRRPGCE: free, but its web port is experimental.
  - GB Studio: free and open source, but limited to the Game Boy's look and constraints.
- **General browser tools aren't built for RPGs.**
  - GDevelop: MIT, editor in the browser, you can sell your games (github.com/4ian/GDevelop).
  - Construct: subscription.
- **Small browser tools are deliberately limited.** Bitsy and PuzzleScript are MIT licensed and share by link, but they're too small for a full RPG.
- **The nearest browser-native RPG tools are early or need coding.**
  - DotWorldMaker: beta, runs on the vendor's servers.
  - RPGJS v5: MIT, but you write TypeScript.
- **Gap:** nothing found that is free, open source, browser-native, RPG-specific, simple to script, shareable by link, and lets you sell your game. The gap is real but narrow, and GDevelop and GB Studio each miss by only one or two of those.
- **Risk:** Gotcha Gotcha Games has announced a new RPG Maker (rpgamer.com, March 2026). Whether it will run in a browser is unknown.

## Revival precedents (GitHub, October 2026)

- **What worked:**
  1. Making old games playable first, especially in a browser.
  2. Regular jams.
  3. A curated showcase.
  4. Releases that are frequent and visible.
- **The limit:** without a hook, nostalgia alone keeps a community in the tens.

**The evidence:**

- **Very strong:** OpenRCT2 (16.4k stars, which is GitHub's measure of interest; monthly releases), OpenTTD (8.4k), ScummVM (2.8k).
- **Strong:** Adventure Game Studio (853 stars). Its MAGS monthly competition has never stopped.
- **Steady:** EasyRPG Player (RPG Maker 2000/2003, 1.2k stars). New games still ship playable in the browser.
- **Small but alive:**
  - ZZT. Now that the old backlog is nearly used up, new ZZT games come mostly from Museum of ZZT jams.
  - OHRRPGCE (100 stars).
  - Bitsy. Its jams draw 10–13 entries.

## RPG Toolkit today (2026-10-10)

- **rpgtoolkit.net** is a placeholder page ("lost in the dungeons"). It links to a Discord, a GitHub organization and a 3.2.1b download.
- **Discord** (discord.gg/ckNQwgW): about 357 members, about 40 online. Message activity is unknown.
- **GitHub organization "rpgtoolkit":** 12 repositories, all dormant since 2017. This includes a stalled 4.x/HTML5 rebuild from 2015–17.
- **RPGWizard** (swordmaster2k/rpgwizard), an earlier successor project, has been quiet since 2020 (last push 2024-09).
- **aljopro/rpgtoolkit-reawakened** is on GitHub (0 stars, pushed 2026-10-10). It is Jensen's own public repository for this project.
